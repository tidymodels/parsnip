# Extract survival status

Extract the status from a
[`survival::Surv()`](https://rdrr.io/pkg/survival/man/Surv.html) object.

## Usage

``` r
.extract_surv_status(surv)
```

## Arguments

- surv:

  A single
  [`survival::Surv()`](https://rdrr.io/pkg/survival/man/Surv.html)
  object.

## Value

A numeric vector.
